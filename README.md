# TVBox 聚合器（TVBox Aggregator）

把一堆零散的 TVBox 配置接口，聚合成**一份能用的**配置。

它会持续做四件事：

1. **拉取**你添加的配置接口，拆出里面的采集站（CMS）、扩展插件（jar/js/py）、直播源
2. **体检**每个采集站（能不能搜、有没有片子、延迟多少），按结果排主用/备用
3. **体检**每个插件（静态扫描，不执行代码），拦掉装 APK、杀进程、夹带 so 这类
4. **产出**几份多仓配置和直播 m3u，客户端直接订阅

不内置任何片源，也不提供片源——**你添加什么，它才聚合什么**。

版本：**0.9**（功能可用，接口可能还会调整）

## 特性

**聚合**

- 多档输出：默认档（CMS + 扩展）、全能档（全部扩展）、直连档（只 CMS，不依赖客户端 jar）
- 采集站按「可搜 → 在线 → 延迟」排序，不可搜的站不占主站名额
- 同一个站被多个接口重复收录时自动合并，面板上能看到合并了多少
- 「离源」机制：源接口删了，它带进来的站点继续用；站点自己连续失败才真移除
- 配置接口支持**批量添加**（一次最多 10 个）、**导出 txt** 备份、**导入**恢复（合并去重，不覆盖现有数据）

**安全**

- 插件静态扫描：装包 / 杀进程 / 执行外部命令 / 夹带 `.so` / 压缩炸弹 → 直接不进输出
- 可运行但可疑的行为（起本地代理、申请存储权限、读设备标识）只标注，不拦截

**直播**

- 直播源分「优选 / 备选」，优选按央视+卫视频道数自动排，名额不足就留空
- 大聚合（重新展开 TXT/M3U，3 天）+ 小聚合（只测线路，1 天）
- 只保留央视、卫视、港澳台、地方台；线路按「分片能不能取到 → 码率 → 分辨率 → 延迟」排序
- IPv6 线路单独成组，避免只走 v4 的电视选中打不开的线路

**面板**

- 网页管理：加接口、看体检结果、看每个源贡献了多少站、看日志
- 所有输出都有多个等价地址，客户端随便挑

## 快速开始

不需要克隆仓库，也不需要改文件——复制一段 compose 就能跑。

### 方式一：复制 compose（推荐）

把仓库里 [`docker-compose.yml`](docker-compose.yml) 的内容贴进 Portainer / 群晖「项目」，
或者存成文件：

```bash
curl -fsSLO https://raw.githubusercontent.com/huueng/tvbox-agg/main/docker-compose.yml
```

**只改一行**——把 `- TOKEN=${TOKEN:-}` 换成你自己的密码：

```yaml
      - TOKEN=换成你的密码
```

然后：

```bash
docker compose up -d
docker compose logs -f      # 看第一次聚合，约 3~10 分钟
```

打开 `http://<你的设备IP>:5680/status`。

> **根路径 `/` 是配置文件**（TVBox 的接口地址直接填它），面板在 `/status`。
>
> 默认 compose 用**端口映射**，NAS 面板（飞牛/群晖/Portainer）里能看到端口。
> 代价是容器没有 IPv6——不在意纯 v6 直播源就用它；要完整体检 v6 线路，改用
> `docker-compose.host.yml`。

compose 里其他变量都有默认值，不用动：

| 变量 | 默认 | 说明 |
|---|---|---|
| `TOKEN` | 空 | **建议填**。面板密码 + 写接口令牌；留空 = 不鉴权 |
| `BASE_URL` | 空 | 一般留空，自动用你访问时的地址；走反代再填 |
| `PORT` | `5680` | host 网络下直接占用宿主端口 |
| `INTERVAL` | `6` | 每几小时自动重聚合 |

### 方式一·变体：要测 IPv6 直播源

换成 host 网络版：

```bash
docker compose -f docker-compose.host.yml up -d
```

容器直接使用宿主网络，能解析纯 IPv6 的直播线路。
代价：**端口在 NAS 面板里显示为空**（host 网络不发布端口），实际端口就是 `PORT`。

### 方式二：一行 docker run

```bash
docker run -d --name tvbox-agg \
  --network host \
  --restart unless-stopped \
  -e TOKEN=$(openssl rand -hex 12) \
  -v $PWD/data:/app/data \
  ghcr.io/huueng/tvbox-agg:latest
```

### 方式三：从源码构建（想改代码）

```bash
git clone https://github.com/huueng/tvbox-agg.git
cd tvbox-agg
# 在 docker-compose.yml 的 image 行下面加一行 build: .
docker compose up -d --build
```

### 首次使用

镜像里**没有任何源**，启动后是空的。到面板：

1. 「配置接口」→ 添加你自己的 TVBox 配置地址（单仓 json / 多仓都支持）
2. 等第一次聚合跑完（约 3~10 分钟，取决于接口里有多少站）
3. 「输出」里拿地址，填到电视上的 TVBox

## 输出地址

设该服务地址为 `http://<你的设备IP>:5680`：

| 用途 | 地址 | 说明 |
|---|---|---|
| TVBox 默认档 | `/tvbox.json` | CMS + jar/py 扩展，最通用 |
| TVBox 全能档 | `/tvbox-all.json` | 加上 js 扩展，站点更多 |
| TVBox 直连档 | `/tvbox-direct.json` | 只有 CMS，不加载任何 jar |
| 全量 profile | `/tvbox-full.json` | 含网盘等全部扩展 |
| LibreTV | `/libretv.json` | LibreTV 专用（只吃 CMS） |
| 央视+卫视 | `/live/cctv.m3u` | 直播 m3u |
| 地方台 | `/live/local.m3u` | 副接口，每台 2 条线路 |
| TVBox 直播 | `/live/cctv.json` | TVBox lives 结构 |
| 体检报告 | `/report.json` `/report.md` | 每个站的状态、延迟、可播条数 |
| 面板 | `/status` | 需要登录（根路径 `/` 是配置文件） |
| 健康检查 | `/healthz` | 容器健康检查用 |

## 数据目录

全部状态都在挂载的 `data/` 里（纯 JSON，方便备份和迁移）：

```
data/
├── configs.json        配置接口列表（含主用/备选）
├── sources.json        采集站池子（含离源标记）
├── jars.json           扩展插件池子
├── lives.json          直播源（含优选/备选/屏蔽）
├── state.json          体检状态
├── live_url_cache.json 每条直播线路的测活结果
├── out/                生成好的配置
└── auth.json           面板密码（改过才有）
```

备份只需要打包 `data/`。删掉它等于恢复出厂。
